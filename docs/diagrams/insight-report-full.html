核心结论：①格式(SKILL.md)已事实收敛、注册中心协议互操作为最大缺口；②治理深度双雄 JFrog(供应链安全)与 AWS(运行时+观测)，维度互补须拆开评估；③供应链安全成独立议题(OWASP Top10 定稿)；④Observability 全行业最薄弱；⑤无通用赢家，按组织画像组合选型、先轻后重。

teamai-cli 组件+功能视图（云侧/端侧）

git-native 分发工具。云侧仅 Git 远程仓库（单一事实源）；端侧承载全部编排/渲染/落地逻辑。Versioning/Distribution 强，Security/Observability 双 Gap。

JFrog AI Catalog 组件+功能视图（云侧/端侧）

企业制品库扩展。云侧=注册+版本+签名扫描+ACL 全治理链（供应链安全最强）；端侧=消费与 CI。Observability 缺。

AWS AgentCore + Toolkit 组件+功能视图（云侧/端侧）

五支柱覆盖最高。云侧=注册+策略+运行时+观测全链；端侧=Toolkit CLI 与本地 Agent。运行时策略(Cedar)+观测(CloudWatch)为独有。

OpenAI AgentKit 组件+功能视图（云侧/端侧）

框架+注册表型。云侧=Builder+Connector Registry+Evals+运行态；端侧=ChatKit 嵌入与 SDK。Catalog 口径未决（连接器目录）。

GitHub Copilot Skills 组件+功能视图（云侧/端侧）

强绑定 GitHub。云侧=仓库托管+企业治理+Cloud Agent；端侧=CLI/IDE 与开发者。Catalog 弱、无依赖锁定。

Anthropic Agent Skills 组件+功能视图（云侧/端侧）

格式标准制定者。云侧=plugin marketplace+Claude 运行时；端侧=SKILL.md 文件+Claude Code+使用者。格式生态最成熟、治理最原始。

SkillHub（讯飞）组件+功能视图（云侧/端侧）

开源企业级注册中心。云侧=注册+治理+生命周期（自托管）；端侧=团队消费与贡献。功能全但年轻。
