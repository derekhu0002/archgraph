ArchGraph 带来的额外收益

ArchGraph 的核心目标是构建一种统一的语言，把 harness 设计与目标产品设计放进同一个模型里， 让用户拥有一个统一的视图来作业与观察，从而形成人对 Agent 工作的掌控力。在这个统一模型之上， 还带来以下额外的好处。

跨平台 Agent 编排

一张意图图谱同时驱动 GitHub Copilot、opencode 与 Cursor，共享同一套规则、技能与工具链。

长期记忆

图谱是持久、可查询的记忆——GraphRAG 生命周期与 Neo4j 同步让知识跨会话留存。

最小上下文组装

先武装再行动：只物化当前 Work Package 需要的 Skills 与 Rules。

单一事实来源

每一次变更都映射到图谱元素，设计与代码不再漂移。

验收用例驱动交付

GIVEN-WHEN-THEN 用例从外部验证每个元素，可用 node --test 直接执行。

变更可追溯

每次提交的 commit id 与文件路径都登记回对应的图谱元素。
