# 说自己是世界级记忆系统，拿什么证明？

我们一直说，ArchGraph 是给 AGENT 的长期记忆系统，总纲就一句话：**打造世界级最优秀的 AGENT 长期记忆系统**。

口号好喊，问题跟着就来了——世界级，是多少？

这个问题绕不开。说"很好用""很强"都没用，得有一把尺子。这篇就讲讲，我们是怎么给长期记忆系统立起第一把评测尺子的：基线从哪来、题怎么出、实测跑出什么数，以及那个 100% 到底值不值得高兴。

## 一、先把目标说清楚：读写的极致

立尺子之前，得先知道自己要量什么。

我们的愿景三要素里，"目标"写得很朴素：**读写的极致**——方便高效的读取 + 写入。结构（ArchiMate 意图图 + 分层 SUBVIEW 长期记忆）只是手段，相当于图书馆那套"按类目编号存书"的规则；真正要量的是，想找一本书时，能不能快速、准确地找到。

所以评测不是去测图谱画得多漂亮，而是测**记忆本身读得准不准、写得真不真**。

## 二、去翻业界的卷子：三套公认基准

自己出题容易自嗨，先抄作业。业界在长期记忆评测上，已经有几套公认的基准：

- **LongMemEval**（ICLR 2025）：500 题，测 5 大能力——信息抽取、多会话推理、时间推理、知识更新、拒答。
- **LOCOMO**：约 300 题，偏事实回忆、时间推理、多跳推理，规模小、跑得快。
- **BEAM**：冲到生产规模（100K–10M tokens），测 10 种记忆能力。

公认的跑法是一条流水线：**摄入（Ingest）→ 检索（Search）→ 评判（Evaluate）**。核心指标是准确率、记忆召回、top-k、token 成本和时延；底层还有 MRR、Hit Rate@K 这类 RAG 检索指标。

里面有个数字挺扎心：论文实测，现有商业助手配长上下文 LLM，跨会话记忆要**掉点约 30%**。聊完就忘不是错觉——这恰恰是长期记忆系统的价值空间。而头部玩家能做到 92–94%。

看完就一个感觉：**方法论能借，不用自己重新发明轮子。**

## 三、借维度，不借场景：23 题落进真实图谱

但 LongMemEval 是给"用户和助手闲聊"出的题，后端默认是向量库加事实抽取。我们是 agent 的元记忆——记的是意图图、SUBVIEW、决策、里程碑、踩过的坑。场景不一样。

所以我们的做法是：**借它的 5 大能力维度，换成自己的场景。**

- **信息抽取 5 题**：从记忆里精确取出一个事实。比如"谁是项目总管？"答案要能指着图谱说出来。
- **多会话推理 5 题**：综合多份记忆得出结论。比如"项目愿景固化在了哪几层记忆？"
- **时间推理 5 题**：按 commit 顺序判断先后。比如"升格为总纲，和概念校正，哪个先发生？"
- **知识更新 5 题**：识别旧表述已被新表述取代。比如"愿景现在到底以哪次 commit 为准？"
- **拒答 3 题**：记忆里没有的，正确行为是拒答。比如"图谱里有没有 XYZ 长期记忆系统？"——没有，就该说没有，不能硬编。

每题都是标准三段：**GIVEN 记忆场景 / WHEN 问题 / THEN 期望答案**，再附一条检索提示。全部落在真实意图图上，随时能回放、能复测。

## 四、实测：23 题 100%，平均毫秒级

题出好了，得有个能跑的东西。我们写了个评测 harness（scripts/memory-eval-run.js），全部走 ARGO MCP 的读路径——getArchitectureViewContext、getIntentElementContext、getSystemArchitecture，零 Neo4j 运行时依赖，判定是确定性检查，不靠模型猜。

实测结果：

- 整体 **23/23（100%）**
- 五个维度各 **100%**
- 拒答 **3/3（100%）**——该拒的都知道拒
- 平均单题检索时延约 **5.7ms**（几次运行在 5–6.4ms 之间波动）

跑完第一反应是高兴，第二反应是冷静。这个 100% 到底说明什么？

**说明读路径是可靠的**：记了的事答得出，没记的事会拒答，先后顺序也对，旧表述被新表述取代也拎得清。对一个"记忆系统"来说，这是底线能力的证明。

但它**还没真正加压**。这 23 题都是确定性事实题，判定靠字符串和结构比对，没有对抗性干扰，没有超长会话，也没有开放生成题。说白了，这是一张"基础卷"，不是"竞赛卷"。

## 五、100% 之后，路还长

尺子立起来了，接下来要做的事很清楚：

1. **上 LLM 评判**：开放题由 judge 模型对照 ground truth 打分，替代字符串比对。
2. **加压**：在记忆里埋误导信息测抗干扰，拉长会话序列测规模，贴近真实生产负载。
3. **立门槛**：以 LongMemEval / LOCOMO 头部 92–94% 作"世界级"的量化参照，给 ArchGraph 定自己的目标线。
4. **固化回归**：把评测跑法固化成可执行验收用例，每次改动都跑一遍，跌破基线就报警。

## 最后

"世界级"不是喊出来的，是测出来的。第一版 23 题全过，只是把尺子立起来了；真正的考验在后面。

我们的判断很朴素：**先有基线，再有目标；先测得到，才谈得上改得好。**

你手上那些号称"记得住"的 Agent，敢不敢拿同一套卷子测一下？
